# Sliding Numbers Plus

Native Kotlin Android version of Sliding Numbers Plus, built with Jetpack Compose and Material 3.

## Build and run

- Open the repository root in Android Studio (current stable).
- Use JDK 17 and install Android SDK 36.
- Run the `app` configuration on an Android 6.0+ device or emulator.
- From a shell with JDK 17 and Android SDK 36 configured, run:

```shell
./gradlew testDebugUnitTest assembleDebug
```

The installable debug APK is written to `app/build/outputs/apk/debug/`. GitHub Actions runs JVM tests, a Compose UI smoke test on an emulator, and uploads the debug APK on pushes and pull requests. If all four Android signing secrets are set, CI also builds and uploads a signed release AAB.

## Gameplay

- Levels 1–5 use the 3×3 London board, levels 6–10 use 4×4 Paris, and level 11 onward uses 5×5 New York.
- Tap or drag any tile sharing a row or column with the empty space. The full chain between the tile and gap slides in one move. Boards are shuffled only through legal moves, so every generated puzzle is solvable.
- Earn 1–3 stars according to moves remaining. A completed level always earns at least one star; spending 5 stars continues the same board with 20 extra moves.
- Progress, in-progress boards, preferences, and local score are stored on-device. The app attempts a one-time import of the previous MAUI `snp_v1` preference from the app's existing private SharedPreferences files when upgrading with the same package and signing identity.

## Google Play Games Services

The app includes the Play Games Services v2 client integration, leaderboard and achievements UI, and unlock/submission calls. It intentionally stays in local-play mode until a real game is configured; placeholders do not pretend to be connected.

Before enabling online services:

1. Keep the application ID `com.dpjha.slidingnumbersplus`, create the app in Google Play Console, create/link its Play Games Services project, and publish the configuration for testing.
2. Register OAuth Android clients for the package and each signing certificate SHA-1 (debug, upload, and/or Play App Signing as appropriate); add tester accounts.
3. Create one leaderboard (`Best solve score`, largest value wins) and these achievements in Play Console:
   - `First Arrival`: win a puzzle.
   - `Star Cartographer`: earn a three-star win.
   - `London Clear`: unlock level 6 (complete levels 1–5).
   - `Paris Clear`: unlock level 11 (complete levels 6–10).
   - `New York Clear`: unlock level 16 (complete levels 11–15).
   - `Skyline Collector`: complete 25 puzzles; replays count.
4. Replace the empty `games_app_id` value in `app/src/main/res/values/strings.xml` and the leaderboard/achievement placeholders in `app/src/main/res/values/play_games_ids.xml` with the IDs generated by the linked Play Games Services project.

The leaderboard submits the player's cumulative local score. Each win adds `level × 1,000 + stars × 100 + moves remaining`; configure the Play Console leaderboard for higher-is-better. Online features cannot be fully validated until the Console project, OAuth clients, IDs, and signing certificates are configured.

## CI signing secrets

To enable the optional release AAB job, add these protected repository or organization secrets. Never commit a keystore or signing credentials.

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`
